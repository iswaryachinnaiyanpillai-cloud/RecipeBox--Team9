# 🍽 RecipeBox – Recipe Finder

## 📖 About the Project

RecipeBox is a responsive recipe finder web application developed as part of the ZyoraByte Frontend Internship.

Users can search for recipes using TheMealDB API, view recipe details, and save their favorite recipes using Local Storage.

---

## ✨ Features

- Home Page
- Search Recipes
- Fetch recipes from TheMealDB API
- Loading state
- Error handling
- Add to Favorites
- Favorites stored using Local Storage
- Responsive Design
- Interactive JavaScript

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- TheMealDB API
- Local Storage

## 🚀 How to Run

1. Download the project.
2. Open the project folder.
3. Open **index.html** in your browser.
4. Search recipes and enjoy.
